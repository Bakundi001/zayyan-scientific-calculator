# Zayyan Scientific Calculator

A modern, responsive scientific calculator built with HTML, CSS, and JavaScript.

## About the Project

Zayyan Scientific Calculator is a beginner-friendly web application designed to perform basic arithmetic and scientific calculations through a clean, user-friendly interface.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division.
- Scientific functions: sine, cosine, tangent, logarithms, square root, powers, and factorial.
- Degree and radian angle modes.
- Memory functions: MC, MR, M+, and M−.
- Calculation history saved locally.
- Light and dark themes.
- Keyboard support.
- Responsive design for desktop and mobile devices.
- Progressive Web App support for installation and offline use.

## Technologies Used

- HTML5
- CSS3
- JavaScript
